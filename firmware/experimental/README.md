# Experimental images are private outputs

Use the top-level guarded builder with an exact local stock image. All four output variants carry **DO_NOT_FLASH** in their filenames. The original v8 is preserved as its own reproducibility target; revised CK changes abort association; trace-only and combined-trace variants retain the known UDMA residue defect.

The public package carries source and manifests rather than full vendor-derived images. The private candidate bundle includes the resulting BINs. Neither CRC validity nor offline regression success qualifies physical installation, recovery, SRAM ownership or timing.
