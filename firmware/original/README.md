# Private input directory

No vendor firmware is redistributed here. Supply an ordinary local file through `--stock`. The only accepted patch base is the complete 70144-byte capture with SHA256 `ef5ad9af3f3b290c565a4dc65933d539b7bb8b8051ac9bd45386932a77862c09`.

The original full capture, historical prefix/tail, original CK_COND v8, donor images and obsolete lab images are preserved in the separately supplied private research archive. Their identities are recorded in `../manifests/input_firmware.json`. No input is automatically downloaded or opened as a device.
